# 课钟 · CourseClock

适配上海工程技术大学（SUES）教学系统的课程表应用：从教学服务中心导入本学期课表，按真实时间轴
渲染，在上课前提醒。

仓库名只说明它解决的问题 —— **什么时候上课**。应用本身是单校定制的：它只认 SUES 的教务
系统、分楼作息与 WebVPN，换一所学校，导入器与作息表都得重做。

**本项目是个人独立开发的第三方应用**，与上海工程技术大学没有隶属或合作关系，未获其授权、
审查或背书，也不是该校的官方应用。出现校名只为说明**适配对象**。

---

## 它和普通课表应用的区别

### 上午第 3~5 节按教学楼错峰

同一个「第 4 节」，在不同楼上是三个不同的时间：

| 节次 | 方案 A（A、F 楼，J301） | 方案 B（B、C 楼，J302，其他） | 方案 C（D、E 楼，J303） |
| --- | --- | --- | --- |
| 第 3 节 | 09:55 ~ 10:35 | — | — |
| 第 3、4 节 | — | 09:55 ~ 11:15 | 10:15 ~ 11:35 |
| 第 4、5 节 | 10:40 ~ 12:00 | — | — |
| 第 5 节 | — | 11:20 ~ 12:00 | 11:40 ~ 12:20 |

三者两两交叠、互不包含，所以不能用折中值或嵌套区间代替 —— 只能按楼宇分别取值。应用给每条
安排带上所属楼宇的分组，各取各的时间，因此不存在「选错方案」的系统性偏差。

第 1、2 节与第 6 节及以后三套方案一致。完整的节次-时间对照见
[docs/COURSETIME.md](docs/COURSETIME.md)。

### 真实时间轴

课块的上沿按开始时刻、高度按时长定位，而不是「第 N 节 × 行高」。同一时段重叠的课程并排
显示。09:55 开始的课与 10:15 开始的课，在版面上的高低差就是它们真实的时间差。

## 功能

- **从教学服务中心导入** — 引导完成学校 WebVPN 与统一身份认证，登录后自动进入课表页，
  读回本学期的课程、作息时间与学期起止日期。
- **从分享 / 导出文件导入** — 读取本应用导出的 `.wakeup_schedule` 文件。
- **分楼作息** — 如上。
- **真实时间轴** — 如上。
- **多课表管理**，以及手动增删改课程与自定义颜色。
- **桌面小部件** — 一周课程、当天课程两种，含下课倒计时。
- **上课提醒** — 可设置提前分钟数与常驻通知。
- **自定义时间表** — 可建任意数量的时间表与节次时间，用于夏令时等场景。
- **导出与分享** — `.wakeup_schedule` 文件，以及 ICS 日历文件。
- **外观** — 浅色 / 深色 / 跟随系统，主题色，课表背景图。

## 安装

发布包为 APK，最低支持 Android 5.0（API 21），目标 API 29。

也可以自行构建，见 [docs/BUILDING.md](docs/BUILDING.md)。

## 从教学服务中心导入

1. 主界面点「导入」→「从 SUES 教务导入」。
2. 在打开的页面里登录学校 WebVPN，完成统一身份认证。账号、密码与人机验证全部由你本人
   操作，应用不读取、不保存你的凭据。
3. 登录成功后应用自动走到教学服务中心的课表页，自动读回数据并返回。
4. 自动执行期间会盖一层半透明遮罩并说明当前状态，随时可以按「停止自动脚本」接管。

自动流程只在能确认落在预期页面时继续。一旦出现未预料的页面，会立即停止并转为手动提示，
由你自己操作后按下读取按钮 —— 这个过程不会静默失败。

**关于密码过期提示**：学校会不定时要求修改密码。出现该提示时，应用会自动点「跳过」以便
继续导入，这不会替你修改密码。

**关于证书告警**：登录页出现 SSL 证书验证失败时，应用会把选择权交给你，不会自动放行 ——
登录流程里会出现你的统一身份认证凭据，静默放行等于把密码暴露给中间人。

## 添加桌面小部件

小部件**只从桌面的小部件列表添加**：长按桌面空白处 → 添加小部件 / 小部件列表 → 选择「课钟」，
然后选择当天课程（4×2）或一周课程（4×4）。周视图会先让你选一张课表，日视图跟随默认课表。

应用内**不提供**添加入口：各厂商桌面在这件事上没有可用的通用做法 —— 要么不支持
`requestPinAppWidget`，要么（HyperOS 实测）接受请求却既不弹确认框、也不真的落一个实例，
点下去只会把用户丢进一个第三方列表里自己找。与其留一个走不通的按钮，不如不做。

列表顺序由桌面决定，应用不能指定排名。选择器显示静态课程示例，实际内容以所选课表为准。
桌面小部件跟随系统浅色/深色模式，不受应用内「显示主题」选项影响。
Android 12 及以上由桌面解析表头文字和图标颜色，与底板使用同一主题；课程位图在主题配置变化时刷新。

## 后台运行设置

HyperOS 上首次点击「后台运行不受限制」打开厂商电池管理，将课钟设为「无限制」。
返回后确认已设置，入口改为「加入 AOSP 白名单」，再次点击打开 Android 系统的电池优化
豁免确认页面。两者是独立设置：HyperOS 状态由用户确认，AOSP 状态由系统实时查询，
不以历史点击记录判断授权。完成后仍可点开入口重新设置。其他系统直接进入 AOSP 步骤。

## 界面外观

设置、课表管理、课程管理及编辑表单共用浅深色文字与表面颜色，卡片和输入框使用 8dp 圆角，
底部面板使用 16dp 顶部圆角。浅色模式提高次要文字对比，深色模式使用中性灰区分页面和内容。
课程管理中的课名最多显示两行，卡片随内容和字体大小增高；时间信息使用主题文字色，避免浅色课程配色导致难以辨认。

## 课程详情

点击课表中的课程查看课名、起止时间、节次、周次、地点和教师；免听、重修、非本周仅在适用时显示。
重叠课程共用一个详情面板：用左右箭头切换，或点击「重叠课程 N / M」直接选择。
仅列出当前查看周有安排且时间相交的课程，按各自楼宇作息计算，首尾相接不算重叠；
时间未设置时回退到节次判断。编辑和删除对应当前选中的课程。
删除先选择「这条安排」或「全部安排」，再确认；不再通过长按直接删除整门课程。
「提醒设置」进入全局上课提醒设置。长课名、地点及大字体内容可以在面板内滚动查看。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `INTERNET` | 导入课表时访问学校系统 |
| `VIBRATE` | 上课提醒 |
| `RECEIVE_BOOT_COMPLETED` | 重启后重排课程提醒（系统会清空闹钟） |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 申请 Doze 白名单，否则深度待机后早课提醒会被推迟 |

导入的课表只保存在本机。应用不向任何第三方服务器上传数据，也不含统计或崩溃上报 SDK。

## 构建与测试

前置：JDK 21、Android SDK。发布签名需要自行提供密钥库，口令只从环境变量
`WAKEUP_KEY_PASSWORD` 读取，不落盘。

| 目标 | 命令 |
| --- | --- |
| 作息换算自测 | `powershell -ExecutionPolicy Bypass -File coursetime/verify.ps1` |
| App 单元测试 | `cd android; ./gradlew test` |
| 调试包 | `cd android; ./gradlew assembleDebug` |
| 发布包（签名） | 设置 `WAKEUP_KEY_PASSWORD` 后 `cd android; ./gradlew assembleRelease` |

细节见 [docs/BUILDING.md](docs/BUILDING.md)。
